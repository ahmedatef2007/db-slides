Case study 1

Car manufacturer: map it

Narrative recap

  • MODEL: unique name, suffix, engine size
  • PART: id code, description, year, many images
  • MODEL M:N PART
  • Each model produced at one FACTORY (one per city)
  • FACTORY: machines, capacity, computer system (OS, DBMS, Internet)
  • Parts and model produced in the same factory

Your task

  • Draw the ERD (Lesson 2 method)
  • Apply steps 1–7
  • Underline PKs, mark FKs
  • Ternary or two binaries? Check model → factory

Model answer: FACTORY(_City_, Machines_no, Capacity, OS, DBMS, Internet); MODEL(_Name_, Suffix, Engine_size, Factory_city*); PART(_Id_code_, Description, Prod_year); PART_IMAGES(_Id_code*_, _Image_); MODEL_PART(_Model_name*_, _Id_code*_). No ternary: each model has one factory, so 'same factory' holds automatically; the factories that make a part come from joining MODEL_PART with MODEL.
