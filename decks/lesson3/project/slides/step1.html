Step 1

Mapping regular (strong) entity types

  • Create one table per regular entity
  • Simple attributes → columns
  • Composite → only its parts (Fname, Lname)
  • Derived → usually not stored (compute it or use a view)
  • Choose one key as PK; others → UNIQUE
