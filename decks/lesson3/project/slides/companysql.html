Preview: the mapping as SQL

CREATE TABLE works_on (

  essn   CHAR(9)      NOT NULL,

  pno    INT          NOT NULL,

  hours  DECIMAL(4,1) CHECK (hours >= 0),

  CONSTRAINT pk_works_on PRIMARY KEY (essn, pno),

  CONSTRAINT fk_wo_emp  FOREIGN KEY (essn)

      REFERENCES employee (ssn),

  CONSTRAINT fk_wo_proj FOREIGN KEY (pno)

      REFERENCES project (pnumber)

);

Composite PRIMARY KEY = step 5's rule.

Each FK becomes a FOREIGN KEY … REFERENCES constraint.

Total participation and business rules become NOT NULL and CHECK.
