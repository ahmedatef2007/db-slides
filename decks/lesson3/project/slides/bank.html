Banking system: map it

Narrative recap

  • BRANCH: unique name, unique address, phone
  • CUSTOMER: unique ID, name, address, phones
  • Each customer has one ACCOUNT: number, amount, last transaction date (D/M/Y)
  • TRANSACTION: number, type, date, amount, time, branch
  • Any customer, any type, any branch

Your task

  • Two candidate keys in BRANCH: which is the PK?
  • Where does the 1:1 customer–account FK go?
  • Map TRANSACTION and its two FKs
  • Is last transaction date derived?
