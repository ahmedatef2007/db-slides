Normal forms

First normal form (1NF)

A table is in 1NF if every cell holds a single, atomic value: no multi-valued attributes, repeating groups or composite attributes.

To reach 1NF

  • Move each repeating group to a new table, carrying the PK as a FK
  • Move each multi-valued attribute to a new table, carrying the PK as a FK
  • Split composite attributes into one column per part

Repeating group?

A set of multi-valued columns that belong together, e.g. Subject + Description + Grade for one student.
