Functional dependencies

Three types of functional dependency

Full

X → Y is full if removing any attribute from X breaks the dependency.

  • {Ssn, Pnumber} → Hours

Partial

X → Y is partial if some attribute can be removed from X and the dependency still holds.

  • {Ssn, Pnumber} → Ename (Ssn alone is enough)

Transitive

X → Y is transitive if X → Z and Z → Y, where Z is not a key (nor part of one).

  • Ssn → Dnumber → Dname
