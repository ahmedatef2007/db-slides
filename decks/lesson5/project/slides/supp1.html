Suppliers: 1NF → 2NF → 3NF

1NF

SUPPLY ( S#, Country, Currency, P#, Qty )

2NF

SUPPLIER ( S#, Country, Currency )

SUPPLIER_PART ( S#, P#, Qty )

3NF

SUPPLIER ( S#, Country )

COUNTRY ( Country, Currency )

SUPPLIER_PART ( S#, P#, Qty )

Every value is already atomic, so the original relation is already in 1NF. The split into SUPPLIER and SUPPLIER_PART removes the partial dependency S# → Country, Currency: that is the 2NF step.
