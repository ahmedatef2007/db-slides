Normal forms

Second normal form (2NF)

A table is in 2NF if it is in 1NF and no non-key attribute is partially dependent on the primary key.

To reach 2NF

  • Move attributes that depend on part of the key to a new table
  • Take that part of the key with them as the new table's PK

Already in 2NF if any is true

  • The PK is a single column
  • All columns are part of the PK
  • Every non-key column depends on the whole PK
