Functional dependencies

Functional dependency (FD)

A → B (A determines B) if every value of A is associated with exactly one value of B.

FDRead as
Ssn → EnameA social security number determines one employee name
Pnumber → {Pname, Plocation}A project number determines the project's name and location
{Ssn, Pnumber} → HoursAn employee and a project together determine the weekly hours

FDs come from the meaning of the data (business rules), not from looking at a few rows.

FDs are constraints derived from the meaning and interrelationships of the attributes. FDs and keys are used to define normal forms. A set of attributes A functionally determines B if the value of A determines a unique value for B.
