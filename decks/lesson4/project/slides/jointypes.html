Joins

Types of join

INNER JOIN

Only rows with a match in both tables.

LEFT OUTER JOIN

All rows of the left table + matches; NULLs where none.

RIGHT OUTER JOIN

All rows of the right table + matches; NULLs where none.

FULL OUTER JOIN

All rows of both tables, matched where possible, NULLs elsewhere.

CROSS JOIN

Cartesian product: every row with every row.

SELF JOIN

A table joined to itself using two aliases.
