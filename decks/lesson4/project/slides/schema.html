Database schema

CREATE SCHEMA hr AUTHORIZATION ahmed;

 

CREATE TABLE hr.employee ( ... );

 

SELECT * FROM hr.employee;

A schema is a named group of related objects (tables, views, indexes…) inside a database.

It has one owner who can change the structure of any object in it. A schema is not a person, but it is associated with a database user.
