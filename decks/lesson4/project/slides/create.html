DDL

CREATE TABLE

CREATE TABLE students (

  id          INT          PRIMARY KEY,

  first_name  VARCHAR(50)  NOT NULL,

  last_name   VARCHAR(50)  NOT NULL,

  email       VARCHAR(100) UNIQUE,

  city        VARCHAR(50)  DEFAULT 'Cairo',

  birth_date  DATE,

  gpa         DECIMAL(3,2) CHECK (gpa BETWEEN 0 AND 4)

);

Syntax

CREATE TABLE name (column TYPE [constraint], …, [table constraints]);

Every column gets a type; constraints can be written inline or at the end.
