CASE: if-then-else inside a query

SELECT fname, salary,

       CASE

         WHEN salary >= 40000 THEN 'High'

         WHEN salary >= 25000 THEN 'Medium'

         ELSE 'Low'

       END AS salary_band

FROM   employee;

CASE returns the first matching branch. It can be used in SELECT, WHERE, ORDER BY and inside aggregates.

SUM(CASE WHEN sex = 'F' THEN 1 ELSE 0 END) counts women per group.
