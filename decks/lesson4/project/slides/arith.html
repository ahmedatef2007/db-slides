SELECT

Expressions and column aliases

SELECT fname, salary, salary + 300

FROM   employee;

 

SELECT fname,

       salary,

       10 * (salary + 300) AS proposed_salary

FROM   employee;

Precedence

  • * and / before + and -
  • Parentheses first

Aliases with spaces need quotes: AS "Proposed salary".
