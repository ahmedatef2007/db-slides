Named constraints and foreign keys

CREATE TABLE department (

  dnumber   INT         CONSTRAINT pk_dept PRIMARY KEY,

  dname     VARCHAR(30) NOT NULL CONSTRAINT uq_dname UNIQUE,

  mgr_ssn   CHAR(9)

);

 

CREATE TABLE employee (

  ssn       CHAR(9)      CONSTRAINT pk_emp PRIMARY KEY,

  fname     VARCHAR(30)  NOT NULL,

  salary    DECIMAL(10,2) CONSTRAINT ck_sal CHECK (salary > 0),

  super_ssn CHAR(9)      REFERENCES employee (ssn),

  dno       INT          NOT NULL,

  CONSTRAINT fk_emp_dept FOREIGN KEY (dno)

      REFERENCES department (dnumber)

);

Name your constraints: error messages then say ck_sal instead of SYS_C00123.

A FK must reference a PRIMARY KEY or UNIQUE column.

department.mgr_ssn → employee is added later with ALTER: the two tables reference each other.
