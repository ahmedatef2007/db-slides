Cartesian product (CROSS JOIN)

SELECT e.fname, p.pname

FROM   employee e

CROSS  JOIN project p;

 

-- the same thing by accident:

SELECT e.fname, p.pname

FROM   employee e, project p;   -- no join condition

Every row of the first table paired with every row of the second: 8 employees × 6 projects = 48 rows.

Useful on purpose for generating combinations (e.g. all sizes × all colors); usually a sign of a missing join condition.
