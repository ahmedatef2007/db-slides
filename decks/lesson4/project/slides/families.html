Foundations

Four families of SQL statements

DDL

Data Definition: structure

  • CREATE
  • ALTER
  • DROP
  • TRUNCATE

DML

Data Manipulation: rows

  • SELECT
  • INSERT
  • UPDATE
  • DELETE

DCL

Data Control: permissions

  • GRANT
  • REVOKE

TCL

Transaction Control

  • COMMIT
  • ROLLBACK
  • SAVEPOINT

SQL is a declarative language: you say what you want; the DBMS's optimizer decides how to get it.
