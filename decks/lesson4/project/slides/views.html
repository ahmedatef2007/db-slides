Views

Views: virtual tables

What a view is

  • A stored SELECT with a name
  • Contains no data of its own
  • Based on base tables (or other views)
  • Queried like a table

Why use views

  • Restrict access: show only some columns or rows
  • Simplify complex joins for users
  • Data independence: apps survive table changes
  • Different views of the same data per user group
