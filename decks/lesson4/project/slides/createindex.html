Indexes

Creating and removing indexes

CREATE INDEX emp_salary_idx ON employee (salary);

 

-- composite: helps WHERE dno = ? AND lname = ?

CREATE INDEX emp_dno_lname_idx ON employee (dno, lname);

 

CREATE INDEX emp_email_idx ON employee (email);

 

DROP INDEX emp_salary_idx;            -- Oracle, PostgreSQL

DROP INDEX emp_salary_idx ON employee; -- SQL Server, MySQL

Column order matters in a composite index: it helps queries on dno or dno + lname, not on lname alone.

Check whether a query uses an index with EXPLAIN (PostgreSQL, MySQL) or the execution plan (Oracle, SQL Server).
