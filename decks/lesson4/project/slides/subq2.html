Subqueries

Subqueries returning one value

-- department of the highest-paid employee

SELECT dname

FROM   department

WHERE  dnumber = (SELECT dno

                  FROM   employee

                  WHERE  salary = (SELECT MAX(salary)

                                   FROM   employee));

Subqueries can nest. Read them inside out: the max salary → whose department → its name.

If a single-row subquery returns more than one row (two top earners in different departments), = fails. Use IN to be safe.
