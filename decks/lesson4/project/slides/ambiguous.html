Joins

Ambiguous columns and table aliases

-- both tables have a column called name and id

SELECT d.name AS department, e.id, e.name, e.salary

FROM   department d

JOIN   employee   e ON d.id = e.dept_id

ORDER  BY d.name;

When two tables share a column name, prefix it: department.name or with an alias d.name.

Prefixing every column makes queries easier to read and avoids errors when a new column is added.
