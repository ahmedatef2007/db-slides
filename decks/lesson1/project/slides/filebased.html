Files to databases

The file-based approach

Each program defines and manages its own data files. It worked when computers ran one job at a time.

Sales program

  • customers.dat
  • orders.dat

Billing program

  • customers.csv (again)
  • invoices.dat

HR program

  • employees.xls
  • payroll.dat

Problem: The same customer lives in two files with two formats. Change an address in Sales and Billing still sends the invoice to the old one.
