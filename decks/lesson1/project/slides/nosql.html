Beyond relational

Non-relational (NoSQL) databases

No fixed tables, rows or foreign keys. Each store uses a data model optimized for one kind of data and access pattern.

  • NoSQL = Not Only SQL
  • Usually schema-flexible
  • Built to scale out across many servers
  • Some offer SQL-like query languages (e.g. Cassandra CQL)
