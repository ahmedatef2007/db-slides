Data models

Three kinds of data models

Lesson 2

Conceptual (high level)

Close to how users think: entities, attributes, relationships.

  • Example: an ERD

Lesson 3

Logical (representational)

How data is organized for a DBMS, independent of storage.

  • Example: the relational model (tables)
  • Others: document, graph

Lesson 4

Physical (low level)

How data is stored on disk and the access paths to find it.

  • Example: files, pages, indexes

A data model is a set of concepts used to describe the structure of a database, the relationships in it and the constraints on it.
