The DBMS

What a DBMS does for you

Define

Data types, structures, constraints (DDL)

Store & retrieve

Efficient storage, indexes, a query language (SQL)

Share

Many users and programs on the same data

Concurrency control

Simultaneous updates without conflicts (transactions)

Security

Who may see or change what (GRANT / REVOKE)

Integrity

Constraints keep data valid (PK, FK, CHECK)

Backup & recovery

Restore a consistent state after a crash

Data dictionary

A catalog describing every object (metadata)
