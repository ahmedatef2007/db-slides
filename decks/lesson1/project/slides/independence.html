Architecture

Data independence

The capacity to change the schema at one level without changing the level above it.

Logical data independence

Change the conceptual schema without changing external schemas or programs.

  • Add a column Email to EMPLOYEE
  • Split a table; old views still work

Physical data independence

Change the internal schema without changing the conceptual schema.

  • Add an index on Salary
  • Move data files to a faster disk
