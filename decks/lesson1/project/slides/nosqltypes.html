Document stores pair each key with a complex structure (a document). Key-value stores: each key maps to one value, like a dictionary; the simplest NoSQL type. Wide-column stores use tables, rows and columns, but column names and formats can vary per row. Graph stores use nodes, edges and properties for semantic queries.
