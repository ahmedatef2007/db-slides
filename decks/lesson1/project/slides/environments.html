Beyond relational

Where databases run

Centralized / mainframe

One powerful machine; users connect from terminals.

Client/server

The database lives on a server; each user's PC runs the client application.

Three-tier / web

Browser → web/app server → database server. Only the server needs the app installed.

Distributed

Data is spread over several sites but looks like one database to users.

Cloud (DBaaS)

A managed service: the provider runs backups, patching and scaling, e.g. Amazon RDS, Azure SQL, Cloud SQL.

Embedded

The database is a library inside the app: SQLite in every phone and browser.
