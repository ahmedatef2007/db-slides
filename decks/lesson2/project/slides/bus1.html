Case study 2

Country bus company (1/2)

A country bus company owns a number of buses. A bus is characterized by number, number of chairs, options (AC, Automatic, PS) and brand name.

Each bus is allocated to a particular route, although some routes may have several buses. Each route is described by KM, start point, end point and duration.
