Keys

Key attributes

Simple key

One attribute is unique.

  • Ssn of EMPLOYEE

Composite key

A combination of attributes is unique; no part alone is.

  • (ID, Application_no)
  • Model (Name, Suffix)

Candidate keys

An entity can have more than one key.

  • EMPLOYEE: Ssn and Email
  • Each key is underlined separately

Note: There is no primary key in an ERD. We pick one candidate key as the primary key later, during mapping (Lesson 3).

An entity type with no key of its own is a weak entity type.
